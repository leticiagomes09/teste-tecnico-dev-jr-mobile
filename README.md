# Perfil Dev Jr

---

## 📌 Descrição

Aplicativo mobile desenvolvido em React Native com Expo como parte de um desafio técnico simulando uma vaga de Desenvolvedor Mobile Júnior.

O objetivo do projeto é apresentar um perfil profissional de forma organizada, utilizando navegação por abas inferiores (Bottom Tabs), com informações pessoais, habilidades, projetos e contato.

---

## 🛠️ Tecnologias utilizadas

- React Native  
- Expo  
- JavaScript  
- React Navigation  
- Expo Vector Icons  
- Git  
- GitHub  

---

## ⚙️ Funcionalidades implementadas

- Navegação por abas inferiores (Bottom Tabs)
- Tela de perfil com foto, nome, cargo e informações pessoais
- Tela de habilidades com lista de competências técnicas
- Tela de projetos com apresentação de aplicações desenvolvidas
- Área de contato com e-mail, GitHub e LinkedIn
- Campo de mensagem com botão de envio
- Interface estilizada com StyleSheet
- Uso de componentes do React Native:
  - View
  - Text
  - Image
  - FlatList
  - TextInput
  - TouchableOpacity

---

## 📱 Telas do aplicativo

### 👤 Perfil
Apresenta as informações principais do desenvolvedor, incluindo:
- Foto de perfil
- Nome
- Cargo profissional
- Breve descrição pessoal
- Informações rápidas (localização, área de estudo e tecnologia)

---

### 🚀 Habilidades
Exibe uma lista com as principais tecnologias estudadas e utilizadas no desenvolvimento mobile.

- Lista renderizada com FlatList
- Organização visual em cards

---

### 📂 Projetos / Contato
Apresenta projetos desenvolvidos durante os estudos:

- App Contador
- App Busca CEP
- App Lista de Tarefas
- Guia Turístico Digital

Também contém:
- Informações de contato (e-mail, GitHub, LinkedIn)
- Campo de mensagem
- Botão de envio de contato

---

## 🧩 Organização do código

O projeto foi organizado de forma modular e simples:

- `App.js` → Configuração da navegação (Bottom Tabs)
- `screens/PerfilScreen.js` → Tela de perfil
- `screens/HabilidadesScreen.js` → Tela de habilidades
- `screens/ProjetosScreen.js` → Tela de projetos e contato
- `assets/` → Imagens do projeto

Toda a estilização foi feita utilizando **StyleSheet**, seguindo boas práticas de organização e separação de estilos.
